# Project environment (Python 3.10; tested with 3.10.12 on Ubuntu 22.04 under WSL2)
#
# Reproduce with:
#   python3.10 -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#   pip install --no-deps simglucose==0.2.11
#   pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
#
# CPU torch is enough: the policy is a 64x64 MLP and all runs used --device cpu.
#
# Two deliberate deviations from simglucose's declared metadata, both required:
#
# 1. setuptools<81. simglucose calls pkg_resources.resource_filename to locate its
#    parameter CSVs. pkg_resources was removed in setuptools 81, so a current
#    setuptools breaks every simglucose import.
#
# 2. simglucose installed with --no-deps. Its metadata pins gym==0.9.4 (from 2017,
#    does not build on Python 3.10) and gymnasium~=0.29.1 (incompatible with
#    Stable-Baselines3 2.9). Neither pin is needed: only simglucose.envs imports
#    gym, and that module is never used here. The ODE core, sensor, pump and
#    scenario generator import cleanly without it. The top-level
#    simglucose/__init__.py does import gym to register a legacy env, which is
#    neutralised by a small shim in our own env module rather than by editing
#    site-packages.
#
#    Consequence: `pip check` reports one expected complaint about the gymnasium
#    pin. It is deliberate and safe.
